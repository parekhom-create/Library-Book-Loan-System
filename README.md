# Library Book Loan System

## Project Overview
The Library Book Loan System is a desktop application developed using Python and Tkinter. It helps librarians and library members manage books, borrowing, returns, and active loans.

## Features
- Librarian and member login
- Add new books
- Register library members
- Borrow and return books
- Search books by ID, title, or author
- View active loans and due dates
- Save and load data using CSV files
- Graphical user interface using Tkinter

## Technologies Used
- Python 3.10+
- Tkinter
- CSV
- Object-Oriented Programming (OOP)

## How to Run
1. Install Python 3.10 or later with Tkinter support.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python library_system.py
```

## Project Structure
- `library_system.py` – Main Python application
- CSV files – Automatically generated local data storage

## Learning Outcomes
This project demonstrates Python programming, classes and objects, file handling, input validation, GUI development, and basic library management operations.

## Note
This is an educational project. The sample login credentials and CSV-based password storage are intended for demonstration only, not production use.
